Post 4:5 · Instagram, Facebook, Telegram, WhatsApp

Historia 9:16 · Instagram, estado de WhatsApp

Revisión

Las partidas pendientes no salen a ninguna red hasta que las apruebes. Al aprobar, GitHub publica en Telegram, Facebook e Instagram en 1 o 2 minutos y actualiza la web.

Ajustes de este navegador

Para enviar y aprobar partidas este navegador necesita un token de GitHub. Solo se guarda aquí; nunca se sube al repositorio.

Cómo crear el token (una sola vez)

  1. Entra a github.com → Settings → Fine-grained tokens → Generate new token.
  2. Nombre: Publicador de partidas. Vencimiento: el que prefieras, por ejemplo 1 año.
  3. Repository access → Only select repositories → tazon-partidas.
  4. Permissions → Repository permissions → Contents: Read and write. Nada más.
  5. Genera el token, cópialo y pégalo arriba.

Cada persona del equipo puede tener su propio token. Si un teléfono se pierde, borra ese token en GitHub y listo.
